# Language Tutor

Веб-приложение и расширение Chrome для изучения английского во время просмотра YouTube. Планируются кликабельные субтитры, перевод слов в контексте, личный словарь, оценка сложности видео и чат с AI-агентом. Веб-приложение и расширение используют один учебный профиль одного учащегося. Приложение открывается без регистрации и входа; AI работает через личную подписку Codex/ChatGPT.

Итоговая поставка — локальный запуск через Docker Compose. Веб-приложение и расширение используют локальный backend; для YouTube и внешней LLM требуется интернет. 20 октября 2026 года — контрольная точка демонстрации, а готовность полного MVP определяется критериями приёмки в SPEC.md.

Первый приоритет — веб-сценарий с подготовленным видео, контекстным переводом и сохранением знакомости. Полный MVP также включает учебный чат с настоящими вызовами MCP и расширение Chrome. Комплект поставки: Docker Compose, README, ZIP расширения и результаты приёмки.

Проект находится на этапе подготовки к разработке. В репозитории сохранены спецификация и инструкции; реализация приложения и команды запуска будут добавлены по мере разработки.

## Работа над задачами

Задачи и их блокирующие зависимости находятся в [GitHub Issues](https://github.com/GlebNM/language_tutor/issues). Сначала доступны [проверка подписки и MCP](https://github.com/GlebNM/language_tutor/issues/1), [проверка извлечения субтитров](https://github.com/GlebNM/language_tutor/issues/2) и [веб-просмотр](https://github.com/GlebNM/language_tutor/issues/3). Каждая задача содержит критерии приёмки и способ проверки.

Перед работой агента в новом клоне или worktree восстановите локальные skills. Нужны Node.js, npm, Git и доступ к GitHub:

```sh
npx --yes skills@1.7.2 experimental_install
npx --yes skills@1.7.2 add https://github.com/pydantic/skills/tree/98f591c0886eb11df0bdd57804419e11439efc93/skills/building-pydantic-ai-agents --agent codex --yes --copy
```

Первая команда восстанавливает набор из `skills-lock.json`. Вторая устанавливает закреплённый проектом skill Pydantic AI в `.agents/skills/`. Для совместимости его формата с Codex перенесите корневое поле `compatibility` из frontmatter `SKILL.md` в существующий блок `metadata`, сохранив значение. Установленный в текущем рабочем каталоге skill уже содержит эту адаптацию. Версию самой библиотеки Pydantic AI предстоит закрепить в первой задаче; версия skill её не определяет.

## Планируемый стек

TypeScript, React и Chrome Manifest V3 для интерфейсов; Python, FastAPI, Pydantic AI, MCP и SQLite для сервера. Подробные решения описаны в спецификации.

## Локальные файлы

`.gitignore` исключает локальные skills и настройки агентов в `.agents/` и `.codex/`, секреты и настройки окружения, виртуальные окружения, зависимости, результаты сборки, базы данных, пользовательские данные и журналы. Примеры настроек `.env.example` можно хранить в репозитории.
