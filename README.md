# Language Tutor

Локальное приложение для изучения английского по YouTube: библиотека материалов, импорт SRT/VTT, плеер с кликабельными субтитрами и общий учебный профиль. Интерфейс открывается без регистрации. Данные сохраняются на компьютере учащегося. Для YouTube и AI нужен интернет.

Доступны библиотека и просмотр, живые контекстные карточки, личный словарь, расчет сложности, диагностика и учебный чат с поиском цитат через MCP. Расширение Chrome использует тот же профиль. Готовность полного MVP определяется A1–A19 в [SPEC.md](SPEC.md); фактические результаты и оставшиеся ограничения записываются в [приемке](docs/acceptance.md). 20 октября 2026 года — контрольная точка демонстрации.

## Запуск через Docker Compose

Нужны работающий Docker Engine с Compose v2, доступ к Docker Hub / GHCR / PyPI / GitHub при первой сборке и актуальный Chrome. Откройте терминал в корне проекта:

```sh
cp .env.example .env
docker compose up --build -d
```

Откройте [http://localhost:8765](http://localhost:8765). В установках с отдельной командой Compose используйте `docker-compose` вместо `docker compose`. Порт 8765 должен быть свободен. При конфликте укажите в `.env` другой `APP_PORT`, например `18765`, и соответствующий `ALLOWED_ORIGINS=http://localhost:18765,http://127.0.0.1:18765`; затем открывайте этот порт. API и веб-приложение работают на одном origin; MCP доступен только внутри сети Compose. Приложение публикует порт только на `127.0.0.1`.

Подготовленный материал **Elephants Dream** доступен сразу. Откройте его, начните воспроизведение и перейдите к первой реплике в 0:15. Время берётся из YouTube IFrame Player API с интервалом опроса 100 мс. Нажатие на слово ставит видео на паузу и закрепляет выбранную реплику. Закрытие выбора сохраняет паузу; кнопка «Продолжить просмотр» возобновляет видео. Нажатие на время реплики выполняет перемотку. Если встраивание запрещено или YouTube недоступен, текст остаётся доступен для чтения и есть ссылка на ролик.

Добавьте собственную ссылку YouTube с английским файлом `.srt` или `.vtt` в UTF-8. Ограничения: 2 000 000 байт, 10 000 реплик, 200 000 символов текста. Если файл содержит фрагмент видео, снимите отметку полноты. Приложение не может проверить полноту автоматически. «Заменить дорожку» сохраняет новую версию; старые версии остаются в библиотеке. Идентичное содержимое с теми же временем, языком и видео использует уже сохранённый материал.

Для подключения подписки откройте «Настройки AI». OAuth callback дополнительно публикуется через override:

```sh
docker compose -f compose.yaml -f compose.oauth.yaml up --build -d
```

Кнопка **Continue with ChatGPT** подключает личную подписку через официальный Sign in with ChatGPT для локальных приложений. Отдельный API-ключ не нужен. При первом подключении браузер регистрирует Language Tutor и запрашивает разрешение использовать подписку для AI. После подтверждения нажмите «Проверить подключение»: модель запросит пример через внутренний MCP и вернёт структурированный разбор. 19 октября 2026 года эта живая проверка прошла на `gpt-6.1-sol`, включая повтор после пересоздания контейнера без нового входа; время двух запросов — 8,3 и 10,2 секунды. Отдельная приемка также проверила живые контекстные карточки, диагностику и чат с цитатами; результаты и задержки приведены в [приемке](docs/acceptance.md).

Порт callback задаётся `AI_CALLBACK_PORT` (по умолчанию 1456); этот порт должен быть свободен на хосте. При конфликте выберите в `.env` другой свободный `AI_CALLBACK_PORT` и пересоздайте приложение той же командой. Callback использует `127.0.0.1` и выбранный порт. Библиотека также работает с обычным `compose.yaml`. Порядок подключения, результаты живых AI-сценариев и ограничения описаны в [docs/subscription-proof.md](docs/subscription-proof.md) и [приемке](docs/acceptance.md). Проверка структурированного ответа в настройках использует отдельный пример для проверки подключения.

## Дополнительная настройка сети

Если в Docker не работает унаследованный DNS, но прямой HTTPS доступен, задайте `HOST_CA_BUNDLE` в локальном `.env` (существующий публичный CA bundle вашей сети) и используйте:

```sh
docker compose -f compose.yaml -f compose.oauth.yaml -f compose.dns.yaml up --build -d
```

Этот вариант задаёт DNS `1.1.1.1` и `8.8.8.8` только контейнеру приложения, подключает CA bundle для чтения и сохраняет проверку TLS. Он работает без процесса relay на хосте. Используйте его отдельно от `compose.network.yaml`. В проверенной установке на Colima 20 октября выбран этот вариант; используйте ту же команду при следующих обновлениях. Внутреннее имя `mcp` продолжает разрешаться через Docker.

Чтобы обычная команда `docker compose up --build -d` сохраняла этот выбор, в macOS/Linux добавьте в `.env` строку `COMPOSE_FILE=compose.yaml:compose.oauth.yaml:compose.dns.yaml`. В текущей установке она уже сохранена. Для стандартной сети оставьте `COMPOSE_FILE` незаданным; для возврата к ней удалите эту строку и пересоздайте контейнеры.

Если Docker или Colima не может разрешить адреса OpenAI либо выйти к ним по IPv6, приложение может использовать HTTPS-прокси на хосте. Хост должен сам открывать `auth.openai.com` и `api.openai.com` с обычной проверкой TLS. Этот режим требует Python 3.11+ на хосте и существующий публичный CA bundle, которому доверяет ваша сеть. Он меняет только сеть приложения; ошибка на странице входа OpenAI требует отдельной проверки.

В отдельном терминале запустите узкий CONNECT relay и оставьте его работать:

```sh
python3 scripts/openai-connect-relay.py --port 8766
```

Relay слушает только `127.0.0.1`, разрешает HTTPS только к `auth.openai.com:443` и `api.openai.com:443`, ограничивает соединения и время ожидания. Он передаёт зашифрованные байты без расшифровки TLS и без журналов запросов, заголовков или содержимого. Остановка — `Ctrl+C` в этом терминале.

Добавьте в локальный `.env` две настройки:

```dotenv
OPENAI_HTTPS_PROXY=http://host.docker.internal:8766
HOST_CA_BUNDLE=/absolute/path/to/your/existing-public-ca-bundle.pem
```

Используйте свой существующий публичный CA bundle; если на хосте уже настроен `SSL_CERT_FILE`, укажите тот же файл как `HOST_CA_BUNDLE`. Файл подключается в контейнер только для чтения; сертификаты не копируются в репозиторий или образ. Проверка TLS остаётся включённой. Можно указать уже работающий HTTPS-прокси в `OPENAI_HTTPS_PROXY` вместо relay. Пароли прокси сохраняйте только в локальном `.env`.

```sh
docker compose -f compose.yaml -f compose.oauth.yaml -f compose.network.yaml up --build -d
```

`NO_PROXY` исключает localhost, loopback и `mcp`. Порт MCP остаётся внутренним. Существующее имя `host.docker.internal` должно достигать хоста из контейнера; на Docker Desktop и проверенной Colima оно уже настроено. Не добавляйте замену этого имени на `host-gateway` в Colima. Если порт 8766 занят, выберите другой порт relay и измените `OPENAI_HTTPS_PROXY` соответственно.

При возврате к прямому доступу пересоздайте приложение без `compose.network.yaml` и остановите relay. Базовый запуск не требует этих настроек. Рабочий транспорт к OpenAI не подтверждает успешный OAuth или доступность подписки: их проверяют отдельно.

## Постоянные данные и резервная копия

Том `learning-data` содержит `/data/learning.sqlite3` и отдельный каталог credentials. Обычный `docker compose down` сохраняет том. Проверка пересоздания:

```sh
docker compose down
docker compose up -d
```

Повторно откройте библиотеку. Не добавляйте `-v` к `down`, если хотите сохранить данные. Схема SQLite имеет номер версии; перед обновлением существующей схемы приложение создаёт копию базы рядом с ней. Более новая, неизвестная приложению версия отклоняется. Для ручной резервной копии остановите приложение и скопируйте каталог `/data` из тома; храните копию приватно, поскольку она может содержать credentials. Не публикуйте том или его содержимое в Git.

При первом запуске используется `gpt-6-luna` с уровнем рассуждения `low`. В «Настройках AI» веб-приложения и расширения можно выбрать доступную модель подписки и поддерживаемый ею reasoning. Одна сохранённая пара действует на новые запросы карточек, диагностики и чата и переживает перезапуски. Сохранённые ответы подписаны использованными параметрами; «Сгенерировать заново» получает свежую карточку с текущими настройками. Общий предел ожидания — 30 секунд. `AI_MODEL` задаёт исходную модель установки.

`AI_CALLBACK_PORT` — порт callback, `ALLOWED_ORIGINS` — точный список разрешённых origin через запятую. `.env.example` не содержит секретов. Для расширения добавьте его точный `chrome-extension://<id>` в `ALLOWED_ORIGINS` и пересоздайте приложение. Произвольные внешние origin и Host отклоняются. Параметры API описаны в [локальном OpenAPI](http://localhost:8765/docs).

В настройках есть действие «Удалить мои данные» с отдельным подтверждением. Оно очищает словарь, материалы, диагностику, диалоги, кэши и подключение подписки. После перезапуска установка остается пустой; подготовленный пример можно добавить снова. Отключение одной подписки сохраняет учебные данные.

В «Моих словах» доступны поиск, фильтры и ручные оценки. Ручное «Пока не оценено» сохраняет приоритет над последующей диагностикой. Диагностика сохраняет прогресс; только завершенная проверка применяет предварительные оценки. Для карточек, проверки ответов и чата нужен подключенный ChatGPT. Материалы, словарь и расчет сложности доступны при сбоях AI.

Под плеером находится список «Слова видео». Все слова сразу показаны компактными плитками, сгруппированными по уровням «Пока не оценено», 0, 1, 2, 3. Цвет, число и подпись обозначают знакомость; рядом видна легенда. Плитка показывает базовую форму, часть речи и частоту, а по нажатию раскрывает словоформы, редактор знакомости и реплики. Поиск и фильтры помогают выбрать нужные слова; ручная правка сохраняется в общем словаре и пересчитывает сложность. Нажатие на вхождение перемотает видео и откроет контекстную карточку. Просмотр списка и изменение знакомости доступны без AI. В расширении тот же список находится в боковой панели.

## Разработка и проверки

Python 3.12.11, Node.js 24+ и `uv` нужны для запуска без контейнеров. Версии Python-зависимостей и английской модели spaCy закреплены в `uv.lock`, фронтенда — в `apps/web/package-lock.json`.

```sh
uv sync --frozen
npm ci --prefix apps/web
npm run build --prefix apps/web
uv run uvicorn backend.app.main:create_app --factory --host 127.0.0.1 --port 8765 --no-access-log
```

После сборки backend сам раздаёт веб-приложение. Для разработки через Vite запустите backend с `ALLOWED_ORIGINS=http://localhost:5173,http://127.0.0.1:5173,http://localhost:8765,http://127.0.0.1:8765`, затем `npm run dev --prefix apps/web`; Vite проксирует `/api` на порт 8765.

```sh
uv run pytest backend/tests/test_materials.py
uv run mypy backend/app
uv run ruff check backend
npm run typecheck --prefix apps/web
npm test --prefix apps/web
npm run check --prefix apps/extension
npm test --prefix apps/extension
uv run pytest
```

Backend тестируется через публичный API: импорт, повторное использование, версии, связи ID, словоформы и лимиты. Для английского используются spaCy 3.8.11 и `en_core_web_sm` 3.8.0. Вхождения содержат смещения в кодовых точках Unicode, исходную словоформу и идентичность `language + lemma + part_of_speech`. Неуверенный разбор явно помечается и использует нормализованную словоформу. Исходный текст хранится отдельно от очищенного; повторяющиеся перекрывающиеся фрагменты объединяются, а повторения, произнесённые позднее, сохраняются.

[Результаты проверки материалов](docs/acceptance-materials.md) и [приемка MVP](docs/acceptance.md) содержат фактические результаты по API, браузеру и контейнерам. Скриншоты текущего интерфейса: [слова видео](docs/acceptance/screenshots/video-vocabulary.png), [словарь](docs/acceptance/screenshots/dictionary.png), [диагностика](docs/acceptance/screenshots/diagnosis.png), [чат с цитатами](docs/acceptance/screenshots/chat.png). [Источники и лицензии примера](data/demo/README.md) входят в поставку.

Полный MVP пока не принят. Автоматическое извлечение субтитров не прошло проверку на четырех роликах; текущие проверки расширения в установленном Chrome ещё не завершены. Веб-проверка ролика с запретом встраивания уже прошла во встроенном браузере для [`4xXwFwQmRIM`](https://www.youtube.com/watch?v=4xXwFwQmRIM); детали есть в [результатах проверки материалов](docs/acceptance-materials.md). Медиана живой карточки после оптимизации — 6,6 секунды при ориентире 5 секунд, первого развернутого чата — 16,8 секунды при ориентире 15 секунд. [Ручной список проверок Chrome](docs/chrome-acceptance.md) показывает оставшиеся действия и поля для записи результатов. Репозиторий остается приватным по решению пользователя от 20 октября 2026 года; публичная публикация не требуется для MVP.

## Расширение Chrome

Рабочий код находится в `apps/extension`. [Инструкция установки и подключения](docs/extension.md) описывает установку через режим разработчика, адрес backend и разрешенный origin. [Ручной список приемки Chrome](docs/chrome-acceptance.md) охватывает извлечение, импорт, синхронизацию, общий профиль и оставшиеся проверки панели. Архив собирается без сторонних зависимостей:

```sh
python3 scripts/package-extension.py
```

Результат: `dist/language-tutor-extension.zip`. Панель содержит импорт дорожки, словарь, сложность, диагностику и чат. Автоматическое извлечение пока не прошло обязательную проверку на четырех роликах; при ошибке используйте импорт SRT/VTT. [Журнал исследования](docs/research/caption-extraction-probe.md) сохраняет известные ограничения timedtext. В `apps/extension-probe` остался отдельный исследовательский прототип.

Для ручной приемки выполните `python3 scripts/prepare-chrome-acceptance.py`. Готовые файлы находятся в `dist/chrome-acceptance/`, архив — `dist/chrome-acceptance-files.zip`. [Чек-лист](docs/chrome-acceptance.md) начинается с импорта подготовленного примера и заканчивается формой для отправки фактических результатов.
