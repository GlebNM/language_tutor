# Language Tutor

Веб-приложение и расширение Chrome для изучения английского во время просмотра YouTube. Планируются кликабельные субтитры, перевод слов в контексте, личный словарь, оценка сложности видео и чат с AI-агентом. Веб-приложение и расширение смогут использовать общий учебный профиль.

Проект находится на этапе подготовки к разработке. В репозитории сохранены спецификация и инструкции; реализация приложения и команды запуска будут добавлены по мере разработки.

## Документация

- [SPEC.md](SPEC.md) — требования MVP, архитектура, этапы разработки и критерии приёмки.
- [AGENTS.md](AGENTS.md) — правила работы с проектом.

## Планируемый стек

TypeScript, React и Chrome Manifest V3 для интерфейсов; Python, FastAPI, Pydantic AI, MCP и SQLite для сервера. Подробные решения описаны в спецификации.

## Локальные файлы

`.gitignore` исключает локальные skills и настройки агентов в `.agents/` и `.codex/`, секреты и настройки окружения, виртуальные окружения, зависимости, результаты сборки, базы данных, пользовательские данные и журналы. Примеры настроек `.env.example` можно хранить в репозитории.
