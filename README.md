# Language Tutor

Приложение для изучения английского по YouTube: библиотека материалов, импорт по ссылке YouTube и из SRT/VTT, плеер с кликабельными субтитрами и личный учебный профиль. Несколько пользователей одной установки регистрируются по имени и паролю; у каждого свои материалы, словарь, разговоры, прогресс и подключение AI. Данные сохраняются в постоянном томе Docker Compose. Для YouTube и AI нужен интернет.

Доступны библиотека и просмотр, живые контекстные карточки, личный словарь, расчет сложности, диагностика и разговорная практика с историей слов и поиском цитат через MCP.

В разделе «Прогресс» доступны рост знакомого словаря, дневные изменения, время просмотра, календарь занятий и распределение знакомости. Сохранённые автоматические оценки входят в общие показатели. Выберите период или нажмите на день, чтобы открыть материалы и изменения слов. История размера словаря и время просмотра собираются с обновления; прежний словарь становится исходной точкой. Минуты считаются по фактическому воспроизведению со звуком, с учётом повторов и скорости; подписка AI для статистики не требуется.

С 21 октября 2026 года вся текущая работа относится к web и необходимому ему backend. Разработка, проверки и поставка расширения Chrome отложены до явного решения пользователя заняться расширением; завершение web не запускает этот этап автоматически.

Готовность веб-MVP определяется актуальными критериями в [SPEC §2.1](SPEC.md#21-текущая-работа-только-web), включая разговорную практику A21–A28, пополнение словаря A29–A32 и автоматический отбор слов A33–A35; A1, A11, A15 и части проверок расширения отложены. Фактические результаты записываются в [приемке](docs/acceptance.md).

## Запуск через Docker Compose

Необязательная конфигурация HTTPS описана в [deploy/README.md](deploy/README.md). Основной запуск приведён ниже.

Нужны работающий Docker Engine с Compose v2, доступ к Docker Hub / GHCR / PyPI / GitHub при первой сборке и актуальный Chrome. Откройте терминал в корне проекта:

```sh
cp .env.example .env
docker compose up --build -d
```

Откройте [http://localhost:8765](http://localhost:8765). В установках с отдельной командой Compose используйте `docker-compose` вместо `docker compose`. Порт 8765 должен быть свободен. При конфликте укажите в `.env` другой `APP_PORT`, например `18765`, и соответствующий `ALLOWED_ORIGINS=http://localhost:18765,http://127.0.0.1:18765`; затем открывайте этот порт. API и веб-приложение работают на одном origin; MCP доступен только внутри сети Compose. Приложение публикует порт только на `127.0.0.1`.

Подготовленный материал **Elephants Dream** доступен сразу. Откройте его, начните воспроизведение и перейдите к первой реплике в 0:15. Время берётся из YouTube IFrame Player API с интервалом опроса 100 мс. Нажатие на слово ставит видео на паузу и закрепляет выбранную реплику. Закрытие выбора сохраняет паузу; кнопка «Продолжить просмотр» возобновляет видео. Нажатие на время реплики выполняет перемотку. Если встраивание запрещено или YouTube недоступен, текст остаётся доступен для чтения и есть ссылка на ролик.

Добавьте собственную ссылку YouTube с английским файлом `.srt` или `.vtt` в UTF-8. Ограничения: 2 000 000 байт, 10 000 реплик, 200 000 символов текста. Если файл содержит фрагмент видео, снимите отметку полноты. Приложение не может проверить полноту автоматически. «Заменить дорожку» сохраняет новую версию; старые версии остаются в библиотеке. Идентичное содержимое с теми же временем, языком и видео использует уже сохранённый материал.

Для подключения подписки откройте «Настройки». OAuth callback дополнительно публикуется через override:

```sh
docker compose -f compose.yaml -f compose.oauth.yaml up --build -d
```

Кнопка **Continue with ChatGPT** подключает личную подписку через официальный Sign in with ChatGPT для локальных приложений. Отдельный API-ключ не нужен. При первом подключении браузер регистрирует Language Tutor и запрашивает разрешение использовать подписку для AI. После подтверждения нажмите «Проверить подключение»: модель запросит пример через внутренний MCP и вернёт структурированный разбор. 19 октября 2026 года эта живая проверка прошла на `gpt-6.1-sol`, включая повтор после пересоздания контейнера без нового входа; время двух запросов — 8,3 и 10,2 секунды. Отдельная приемка также проверила живые контекстные карточки, диагностику и чат с цитатами; результаты и задержки приведены в [приемке](docs/acceptance.md).

Если автоматический возврат не сработал, скопируйте полный адрес из строки браузера после входа в ChatGPT, вставьте его в поле «Адрес после входа в ChatGPT» в настройках и нажмите «Завершить подключение». Это работает и если вкладка с адресом `127.0.0.1` показывает ошибку соединения. Передача портов для этого способа не требуется. Адрес одноразовый; не публикуйте его и не отправляйте в переписку. Приложение проверяет точный callback URI, state и PKCE. Для автоматического возврата при локальном запуске остаётся `compose.oauth.yaml`; порт задаётся `AI_CALLBACK_PORT` (по умолчанию 1456).

## Временная модель Ollama Cloud

Добавьте `OLLAMA_API_KEY=...` в локальный `.env` и пересоздайте приложение через `docker compose up -d --build app`. В «Настройки → Учебный AI» включите «Временная модель · gemma4:31b (Ollama Cloud)». Новые AI-запросы используют эту модель без подключения ChatGPT. Выключение тумблера возвращает сохранённую модель ChatGPT и reasoning. Тумблер сохраняется для каждого пользователя отдельно; серверный ключ общий для всей установки и не попадает в браузер. Устанавливать Ollama или скачивать модель не требуется. Контракт подключения: [Ollama Cloud](https://docs.ollama.com/api/openai-compatibility#direct-cloud-access).

## Дополнительная настройка сети

Если в Docker не работает унаследованный DNS, но прямой HTTPS доступен, задайте `HOST_CA_BUNDLE` в локальном `.env` (существующий публичный CA bundle вашей сети) и используйте:

```sh
docker compose -f compose.yaml -f compose.oauth.yaml -f compose.dns.yaml up --build -d
```

Этот вариант задаёт DNS `1.1.1.1` и `8.8.8.8` только контейнеру приложения, подключает CA bundle для чтения и сохраняет проверку TLS. Он работает без процесса relay на хосте. Используйте его отдельно от `compose.network.yaml`. В проверенной установке на Colima 20 октября выбран этот вариант; используйте ту же команду при следующих обновлениях. Внутреннее имя `mcp` продолжает разрешаться через Docker.

Чтобы обычная команда `docker compose up --build -d` сохраняла этот выбор, в macOS/Linux добавьте в `.env` строку `COMPOSE_FILE=compose.yaml:compose.oauth.yaml:compose.dns.yaml`. В текущей установке она уже сохранена. Для стандартной сети оставьте `COMPOSE_FILE` незаданным; для возврата к ней удалите эту строку и пересоздайте контейнеры.

Если Docker или Colima не может разрешить адреса OpenAI либо выйти к ним по IPv6, приложение может использовать HTTPS-прокси на хосте. Хост должен сам открывать `auth.openai.com` и `api.openai.com` с обычной проверкой TLS. Этот режим требует Python 3.11+ на хосте и существующий публичный CA bundle, которому доверяет ваша сеть. Он меняет только сеть приложения; ошибка на странице входа OpenAI требует отдельной проверки.

В отдельном терминале запустите узкий CONNECT relay и оставьте его работать:

```sh
python3 scripts/openai-connect-relay.py --port 8766
```

Relay слушает только `127.0.0.1`, разрешает HTTPS только к `auth.openai.com:443` и `api.openai.com:443`, ограничивает соединения и время ожидания. Он передаёт зашифрованные байты без расшифровки TLS и без журналов запросов, заголовков или содержимого. Остановка — `Ctrl+C` в этом терминале.

Добавьте в локальный `.env` две настройки:

```dotenv
OPENAI_HTTPS_PROXY=http://host.docker.internal:8766
HOST_CA_BUNDLE=/absolute/path/to/your/existing-public-ca-bundle.pem
```

Используйте свой существующий публичный CA bundle; если на хосте уже настроен `SSL_CERT_FILE`, укажите тот же файл как `HOST_CA_BUNDLE`. Файл подключается в контейнер только для чтения; сертификаты не копируются в репозиторий или образ. Проверка TLS остаётся включённой. Можно указать уже работающий HTTPS-прокси в `OPENAI_HTTPS_PROXY` вместо relay. Пароли прокси сохраняйте только в локальном `.env`.

```sh
docker compose -f compose.yaml -f compose.oauth.yaml -f compose.network.yaml up --build -d
```

`NO_PROXY` исключает localhost, loopback и `mcp`. Порт MCP остаётся внутренним. Существующее имя `host.docker.internal` должно достигать хоста из контейнера; на Docker Desktop и проверенной Colima оно уже настроено. Не добавляйте замену этого имени на `host-gateway` в Colima. Если порт 8766 занят, выберите другой порт relay и измените `OPENAI_HTTPS_PROXY` соответственно.

При возврате к прямому доступу пересоздайте приложение без `compose.network.yaml` и остановите relay. Базовый запуск не требует этих настроек. Рабочий транспорт к OpenAI не подтверждает успешный OAuth или доступность подписки: их проверяют отдельно.

## Проверка словаря

Агент подбирает 12–18 слов по вашим ответам через частотный MCP-словарь и создаёт короткие предложения с выделенным словом. Отдельная проверка отбраковывает неоднозначный контекст и подсказки. Ответьте кнопкой «Знаю», «Не уверен» или «Не знаю»; слово можно пропустить. Вводить перевод не нужно. При ошибке подготовки следующий запрос продолжает сохранённую сессию.

После завершения нажмите «Сохранить результат». Самооценки и предположения по частотным группам становятся предварительной знакомостью; ручные оценки имеют приоритет. Можно уйти из диагностики и продолжить позднее либо завершить без результата.

## Постоянные данные и резервная копия

Том `learning-data` содержит `/data/accounts.sqlite3` с учётными записями и сессиями, а также каталоги `/data/users/<id>/` с личной `learning.sqlite3`, настройками AI и credentials. Обычный `docker compose down` сохраняет том. Проверка пересоздания:

```sh
docker compose down
docker compose up -d
```

Повторно откройте библиотеку. Не добавляйте `-v` к `down`, если хотите сохранить данные. Схема SQLite имеет номер версии; перед обновлением существующей схемы приложение создаёт копию базы рядом с ней. Более новая, неизвестная приложению версия отклоняется. Для ручной резервной копии остановите приложение и скопируйте каталог `/data` из тома; храните копию приватно, поскольку она может содержать credentials. Не публикуйте том или его содержимое в Git.

При первом запуске используется `gpt-6-luna` с уровнем рассуждения `low`. В «Настройках AI» веб-приложения можно выбрать доступную модель подписки и поддерживаемый ею reasoning. Одна сохранённая пара действует на новые запросы карточек, диагностики и чата и переживает перезапуски. Сохранённые ответы подписаны использованными параметрами; «Сгенерировать заново» получает свежую карточку с текущими настройками. Общий предел ожидания — 30 секунд. `AI_MODEL` задаёт исходную модель установки.

`AI_CALLBACK_PORT` — порт callback, `ALLOWED_ORIGINS` — точный список разрешённых origin через запятую. `.env.example` не содержит секретов. Произвольные внешние origin и Host отклоняются. Параметры API описаны в [локальном OpenAPI](http://localhost:8765/docs).

В настройках есть действие «Удалить мои данные» с отдельным подтверждением. Оно очищает словарь, материалы, диагностику, диалоги, журнал действий, кэши и подключение подписки. После перезапуска установка остается пустой; подготовленный пример можно добавить снова. Отключение одной подписки сохраняет учебные данные.

В «Моих словах» доступны поиск, фильтры и ручные оценки. Ручное «Пока не оценено» сохраняет приоритет над последующей диагностикой. Диагностика сохраняет прогресс; только завершенная проверка применяет предварительные оценки. Для карточек, проверки ответов и чата нужен подключенный ChatGPT. Материалы, словарь и расчет сложности доступны при сбоях AI.

В «Настройках» можно включить «Автоматически пополнять словарь». Приложение учитывает целиком прослушанные со звуком реплики и нажатия на слова в текущих субтитрах. В конце видео или по кнопке «Завершить просмотр» открывается сводка: непомеченным прослушанным словам предлагается 2, нажатым — 0. Оценки можно исправить, слова — убрать. Закрытие сводки ничего не применяет; «Сохранить в словарь» сохраняет подтверждённый набор. Незавершённые результаты переживают перезапуск; выключение настройки сбрасывает их. Ранее выставленные оценки сохраняются.

Под плеером находится список «Слова видео». Допустимые и вручную добавленные слова сразу показаны компактными плитками, сгруппированными по уровням «Пока не оценено», 0, 1, 2, 3. Цвет, число и подпись обозначают знакомость; рядом видна легенда. Плитка показывает базовую форму, часть речи и частоту, а по нажатию раскрывает словоформы, редактор знакомости и реплики. Поиск и фильтры помогают выбрать нужные слова; ручная правка сохраняется в общем словаре и пересчитывает сложность. Нажатие на вхождение перемотает видео и откроет контекстную карточку. Просмотр списка и изменение знакомости доступны без AI.

Имена, уверенно распознанные в контексте, звуки вроде `hmmmm`, `um`, `uh` и растянутые формы вроде `wooow` автоматически исключаются из учебных списков, сводки, расчётов и целевой практики. Транскрипция и возможность нажать на слово сохраняются. `hello`, `ouch`, `wow` и неоднозначные случаи остаются доступными для изучения. В карточке отсеянного слова нажмите «Добавить в словарь»: любой явный статус, включая «Пока не оценено», добавляет его в учебные списки. Прежние подтверждённые записи сохраняются; отбор работает локально без подписки.

## Добавление видео по ссылке

Нажмите «Добавить материал», вставьте ссылку YouTube и сохраните. Название и доступные английские субтитры загрузятся автоматически: сначала авторские, при их отсутствии — автоматические. Для недоступных дорожек остаётся вкладка «Из файла SRT/VTT».

Опция «Автоматически улучшать автосубтитры с AI» включена по умолчанию. Нужна подключённая подписка; используется выбранная в настройках модель и reasoning. Можно начать просмотр исходника, пока обработка идёт в фоне. После завершения нажмите «Открыть улучшенную версию»: доступны сравнение и возврат к исходнику. Ошибка улучшения сохраняет загруженные субтитры; обработку можно повторить. После перезапуска прерванное задание нужно запустить снова.

Два текстовых агента исправляют пунктуацию, регистр и однозначные ошибки. Тайминги сохраняются; аудио не проверяется, поэтому восстановление сказанного не гарантировано. Специальные речевые модели не нужны. [Исследование методов и промптов](docs/research/youtube-auto-caption-improvement-2026-10-22.md).

## Поиск видео

Откройте «Найти видео», введите английскую тему и выберите длительность. При подключённой подписке можно включить «Сформулировать английский запрос через ChatGPT» и описать тему по-русски. Список постепенно показывает личную лексическую оценку, источник субтитров и встречающиеся изучаемые слова. Выбор нагрузки меняет порядок карточек. «Смотреть с субтитрами» добавляет выбранный материал в библиотеку и открывает плеер, используя уже полученную дорожку.

Для поиска добавьте ключ YouTube Data API v3 в раскрывающейся настройке этого раздела либо в общих настройках. Сначала включите API в Google Cloud и создайте ключ; ограничьте его этим API. Ключ хранится только на сервере в каталоге текущего пользователя с правами 0600. Настройка YOUTUBE_API_KEY в .env — дополнительный вариант оператора; после её изменения пересоздайте Compose. Сохранённый в интерфейсе ключ имеет приоритет. API отвечает только признаком наличия ключа; пригодность ключа и квота проверяются первым поиском.

Без ключа можно вставить полную ссылку YouTube и нажать «Оценить видео». Этот путь получает реальные субтитры и работает без AI. Если в профиле ещё мало оценённых слов, карточка предлагает диагностику, сохраняя долю неоценённой лексики. Оценка касается словаря; она не определяет CEFR или понимание на слух.

Для одной подборки проверяются до десяти кандидатов, максимум две сетевые операции одновременно и одна минута на задачу. Ошибки дорожек показываются отдельно. Повторные запросы используют ограниченный локальный кэш: до 30 дорожек на семь дней; метаданные поиска сохраняются в памяти до часа. Поиск сам не пополняет словарь и не засчитывает просмотр. «Удалить мои данные» очищает кэш и сохранённый ключ этого пользователя; ключ из .env удаляется отдельно оператором. Получение текста зависит от доступности YouTube; распознавание отсутствующих субтитров и платные поставщики не подключены.

## Управление просмотром

Под видео доступны «Назад», «Ещё раз», «Смотреть / Пауза» и «Вперёд». Переходы идут по репликам субтитров. «Цикл реплики» повторяет одну реплику до выключения или перехода в другое место; «Автопауза» останавливает после реплики и ждёт продолжения. Эти два режима включаются отдельно и выключают друг друга. Открытие слова удерживает паузу; закрытие карточки само не запускает видео.

Клавиши: A — назад, S — ещё раз, D — вперёд, пробел — смотреть/пауза, L — цикл, Q — автопауза. Они работают при фокусе на странице, вне полей ввода и окна YouTube; физические A/S/D работают и в русской раскладке. Подсказка находится рядом с кнопками. Скорость выбирается из поддерживаемых текущим видео значений и запоминается в этом браузере. При открытии материала цикл и автопауза выключены.

## Разговорная практика

Откройте «Чат» и начните новый разговор на любую тему или нажмите «Предложить тему». Можно обсуждать несколько сохранённых видео: добавьте их в «Материалы беседы» либо перейдите из просмотра по кнопке «Обсудить в чате». Агент также получает контекст недавних учебных действий, текущее состояние слов и историю изменений знакомости. Он ведёт беседу по-английски, сам употребляет подходящую лексику и кратко исправляет одну полезную ошибку. Помощь можно попросить по-русски.

Ответ появляется постепенно; генерацию можно остановить, а неудачный запрос — повторить. Нажмите на слово завершённого ответа: рядом откроется контекстный перевод с примером и редактором знакомости. На узком экране панель находится под беседой. Оценка общая для чата и видео, черновик сообщения сохраняется при работе с карточкой. Разговоры можно переименовывать, продолжать и удалять; их переписка и сводки раздельны, сведения о словах общие. Полные сообщения сохраняются локально и остаются доступны при сжатии контекста модели и после перезапуска.

Новые ответы и AI-карточки используют подключённую подписку и сохранённые настройки модели. Чтение истории и правка знакомости доступны без AI. [Проверка 22 октября](docs/acceptance/conversation-practice-2026-10-22.json) включает живые ответы, поток, предложения тем, карточку слова, миграцию и браузерный сценарий.

## История учебных действий

Приложение сохраняет клики по словам, полученные карточки перевода (включая кэш), изменения знакомости, исправления базовой формы и отправку вопросов агенту. История хранится локально в той же базе, переживает перезапуск и собирается с момента обновления; прошлые действия не восстанавливаются. Клики сохраняются и без подключения AI, а ошибка перевода не считается полученной карточкой. Эти события сами по себе не меняют знакомость слов.

В чате можно спросить: «Какие слова я недавно открывал?» или «Какие переводы я получал сегодня?». Агент получает историю через MCP `get_recent_activity`, с фильтрами по типу действия, слову, материалу и времени. Для интеграций доступен `GET /api/activity` с продолжением через `next_before_id`. Формат и правила описаны в [SPEC §11.1](SPEC.md#111-журнал-учебных-действий).

## Разработка и проверки

Python 3.12.11, Node.js 24+ и `uv` нужны для запуска без контейнеров. Версии Python-зависимостей и английской модели spaCy закреплены в `uv.lock`, фронтенда — в `apps/web/package-lock.json`.

```sh
uv sync --frozen
npm ci --prefix apps/web
npm run build --prefix apps/web
uv run uvicorn backend.app.main:create_app --factory --host 127.0.0.1 --port 8765 --no-access-log
```

После сборки backend сам раздаёт веб-приложение. Для разработки через Vite запустите backend с `ALLOWED_ORIGINS=http://localhost:5173,http://127.0.0.1:5173,http://localhost:8765,http://127.0.0.1:8765`, затем `npm run dev --prefix apps/web`; Vite проксирует `/api` на порт 8765.

```sh
uv run pytest backend/tests/test_materials.py
uv run mypy backend/app
uv run ruff check backend
npm run typecheck --prefix apps/web
npm test --prefix apps/web
uv run pytest
```

Backend тестируется через публичный API: импорт, повторное использование, версии, связи ID, словоформы и лимиты. Для английского используются spaCy 3.8.11 и `en_core_web_sm` 3.8.0. Вхождения содержат смещения в кодовых точках Unicode, исходную словоформу и идентичность `language + lemma + part_of_speech`. Неуверенный разбор явно помечается и использует нормализованную словоформу. Исходный текст хранится отдельно от очищенного; повторяющиеся перекрывающиеся фрагменты объединяются, а повторения, произнесённые позднее, сохраняются.

[Результаты проверки материалов](docs/acceptance-materials.md) и [приемка MVP](docs/acceptance.md) содержат фактические результаты по API, браузеру и контейнерам. Скриншоты текущего интерфейса: [слова видео](docs/acceptance/screenshots/video-vocabulary.png), [словарь](docs/acceptance/screenshots/dictionary.png), [диагностика](docs/acceptance/screenshots/diagnosis.png), [чат с цитатами](docs/acceptance/screenshots/chat.png). [Источники и лицензии примера](data/demo/README.md) входят в поставку.

Веб-MVP пока не принят: оставшиеся веб-проверки и ограничения перечислены в [приемке](docs/acceptance.md). Веб-проверка ролика с запретом встраивания прошла во встроенном браузере для [`4xXwFwQmRIM`](https://www.youtube.com/watch?v=4xXwFwQmRIM); детали есть в [результатах проверки материалов](docs/acceptance-materials.md). Медиана живой карточки после оптимизации — 6,6 секунды при ориентире 5 секунд, первого развернутого чата — 16,8 секунды при ориентире 15 секунд. Приемка расширения и автоматическое извлечение отложены и не блокируют web. Репозиторий остается приватным по решению пользователя от 20 октября 2026 года.

## Выражения

Открытие видео запускает фоновый поиск фразовых глаголов, идиом и устойчивых сочетаний через подключённую подписку. Во время поиска можно смотреть видео; готовые результаты сохраняются для этой версии дорожки. Ошибку можно повторить в «Выражениях видео».

Нажатие на любую составную часть найденного фразового глагола выделяет все его части, включая раздельное `turn it off`. Выделение работает при любой знакомости и исключении из практики. Идиомы и устойчивые сочетания находятся в раскрываемом блоке. Карточка выражения показывает перевод в исходном контексте и самостоятельную знакомость; отдельное слово доступно под карточкой.

«Выделить выражение» позволяет нажать на несколько нужных слов и выбрать «Разобрать выбранное». Это работает в субтитрах и завершённых сообщениях агента. «Здесь выделено ошибочно» убирает только это вхождение. В разделе «Словарь» откройте вкладку «Выражения»: доступны поиск, типы, оценки и исходные примеры с временем.

Обнаружение и прослушивание не назначают знакомость. Словоформы одного значения объединяются; разные значения `take off` имеют отдельные оценки. Сохранённые выражения доступны без AI и используются агентом в разговорной практике с учётом текущих оценок. Показатели выражений отображаются отдельно от покрытия словами.

План и критерии: [выражения](docs/plans/expressions.md), SPEC F21/A55–A61.

## Учётные записи и перенос прежних данных

На странице регистрации укажите имя (3–32 латинских буквы, цифры, точка, `_` или `-`) и пароль от 12 символов. Имя не зависит от регистра. В боковой панели доступны выход и смена пароля. Сессия действует 30 дней; смена пароля завершает все сессии. Вкладки одного браузерного профиля используют общую сессию. Для одновременной работы разных пользователей используйте разные профили браузера.

При обновлении установки с прежней `learning.sqlite3` первая регистрация требует явно подтвердить перенос профиля и подписки. Выполните её как владелец этой локальной установки. Приложение копирует базу средствами SQLite, настройки и credentials в каталог первой учётной записи; исходные файлы остаются резервной копией и больше не используются приложением. Храните эту копию приватно. Последующие пользователи получают отдельные профили.

Каждый пользователь подключает свою подписку в настройках. Если другой пользователь сейчас проходит OAuth, дождитесь его завершения и повторите подключение. Уже подключённые пользователи могут работать одновременно. «Удалить мои данные» очищает только данные и AI текущего учащегося; учётная запись сохраняется. Восстановление забытого пароля через email пока не предусмотрено. При локальном запуске порты публикуются на loopback. Необязательная конфигурация HTTPS описана в [deploy/README.md](deploy/README.md).

План и критерии: [авторизация и несколько пользователей](docs/plans/multi-user.md), SPEC F19/A44–A48.
