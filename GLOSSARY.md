# Language Tutor

Изучение английского по субтитрам с личным словарём и объяснениями AI. Оба интерфейса используют учебные данные одного учащегося.

## Language

**Учебный профиль (Learning profile)**:
Настройки изучаемого языка, результаты диагностики и правила предварительной знакомости одного учащегося.
_Avoid_: аккаунт, учётная запись приложения

**Личный словарь (Personal dictionary)**:
Оценки знакомости базовых форм слов с учётом языка и части речи, включая ручные исправления учащегося.

**Контекстная карточка (Contextual card)**:
Краткий разбор выбранного вхождения слова: перевод, объяснение и пример с опорой на исходную реплику.

**Учебный агент (Learning agent)**:
Собеседник для разбора лексики с учётом субтитров, личного словаря и предыдущих учебных материалов. Его ответ может включать найденные цитаты и время их появления в видео.

**Подключение подписки (Subscription connection)**:
Разрешение использовать личную подписку Codex/ChatGPT для учебных объяснений, диагностики и диалога. Подключённая подписка определяет доступ к AI, а учебные данные принадлежат учащемуся.
_Avoid_: вход в Language Tutor, аккаунт Language Tutor
