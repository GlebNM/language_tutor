# Управление просмотром по репликам

Дата: 22 октября 2026 года. Статус: пользователь поручил самостоятельно выбрать и реализовать поведение по исследованным примерам конкурентов. Основной сценарий Q1 подтверждён отдельно. Работа: [GitHub #21](https://github.com/GlebNM/language_tutor/issues/21).

Основание: [обзор конкурентов](../research/playback-controls-2026-10-22.md). Обсуждение относится к самостоятельному веб-приложению.

## Согласовано

**Q1. Основной сценарий.** Пользователь ответил «Да»: по умолчанию действует непрерывный просмотр. Повтор, цикл и автопауза включаются учащимся по необходимости. Обычный просмотр не требует подтверждения перехода после каждой реплики.

## Выбранное поведение

1. Единица управления — временной сегмент текущей дорожки субтитров. В промежутке повторяется последняя начавшаяся реплика; до первой повтор и переход вперёд ведут к первой. При перекрытиях для управления выбирается последняя начавшаяся. Недоступные соседние переходы выключены.
2. Панель под видео содержит «Назад», «Ещё раз», «Смотреть / Пауза», «Вперёд», «Цикл реплики», «Автопауза» и скорость. Переход к соседней реплике и разовый повтор запускают её с начала, затем продолжается обычный просмотр.
3. Цикл запускает текущую реплику с начала и повторяет до выключения. Переход к другой реплике или явная перемотка отключает цикл. Пауза, включая клик по слову, останавливает цикл до явного продолжения.
4. Автопауза останавливает после каждой реплики; её текст остаётся видимым. Продолжение ручное. Цикл и автопауза взаимоисключаются; включение одного выключает другой. Выключение режима не возобновляет паузу.
5. Клавиши: физические A/S/D — назад/повтор/вперёд, Space — воспроизведение, L — цикл, Q — автопауза. Повтор удерживаемой клавиши подавляется. В полях ввода, списках, диалогах и системных сочетаниях клавиши не перехватываются; пробел на кнопке сохраняет её обычную активацию. Внутри YouTube iframe действуют его собственные клавиши. Подсказка доступна рядом с панелью.
6. Список скоростей предоставляет YouTube. Интерфейс показывает подтверждённую плеером скорость, включая изменения через родные элементы. Последняя подтверждённая скорость сохраняется в браузере; если видео её не поддерживает, используется обычная. Цикл и автопауза при открытии материала выключены.
7. Исходный образец окончания реплики поступает в учёт прослушивания до автоматической паузы/перемотки. Перемотка обозначает разрыв; пропущенная часть не засчитывается, повтор не дублирует полностью прослушанную реплику. Цикл на конце видео обрабатывается до открытия итоговой сводки.
8. Словарный выбор, закреплённый контекст и закрытие карточки следуют прежним правилам. Скорость и кнопки доступны без AI. Ошибка плеера выключает команды, оставляя текст.

Основные образцы — A/S/D и разовый повтор Language Reactor, ручная автопауза и цикл Yabla/Lingopie. Эта поставка реализует управление отдельными репликами. Произвольные границы A–B, сценарии с числом проигрываний/таймером и показ текста по знакомости являются самостоятельными возможностями дальнейшего развития.

## Проверка

Требования включены в SPEC §5.7, проверка — §13.4 в составе F2/A3/A9. Автоматические сценарии проверяют границы и учёт прослушивания; браузерный прогон проверяет настоящий YouTube, кнопки, клавиатуру, скорость, паузу при выборе слова и вид панели. Результаты записываются в docs/acceptance.md.
