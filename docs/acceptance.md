# Приемка MVP — 19 октября 2026

Полный MVP пока не принят. Приложение собрано через Compose на macOS arm64; для этой установки используется `http://localhost:18765`, а callback подписки — порт 1456. MCP доступен только внутри Compose. Веб-сценарий проверяется через встроенный браузер Codex. Управляемый Chrome в окружении отсутствует, поэтому установленное расширение пока не прошло браузерную приемку.

В этой сессии реализованы словарь, сложность, три AI-сценария, панель расширения и удаление данных. Обязательные пути используют настоящие Pydantic AI Agent и MCP. Контролируемые модели применяются в автоматических тестах; они не заменяют результаты живой подписки.
