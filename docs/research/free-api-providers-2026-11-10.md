# Бесплатный API для Language Tutor

Проверено 10 ноября 2026 года по официальной документации. Требование: регулярная бесплатная квота без обязательного пополнения и без перехода на платный тариф. Доступ к конкретным аккаунтам и API-ключам кандидатов не проверялся; работа нашего приложения через них ещё не подтверждена.

Основной кандидат для пробного подключения — **Cloudflare Workers AI на Workers Free**, модель `@cf/openai/gpt-oss-120b`. У неё документированы вызовы функций, окно 128 000 токенов и совместимый с OpenAI API. Сначала нужно проверить на бесплатном аккаунте структурированный результат и настоящий цикл MCP, затем обсуждение слова и весь процесс генерации. [Модель](https://developers.cloudflare.com/workers-ai/models/gpt-oss-120b/), [OpenAI API](https://developers.cloudflare.com/workers-ai/configuration/open-ai-compatibility/).

## Сравнение

| Провайдер | Что бесплатно | Ограничение для проекта |
| --- | --- | --- |
| Cloudflare Workers AI | 10 000 Neurons ежедневно на Workers Free | Общая вычислительная квота на аккаунт; после её исчерпания запросы завершаются ошибкой. Некоторые модели требуют платного доступа. |
| Groq | Free tier с повторяющимися лимитами | Для `openai/gpt-oss-120b`, `openai/gpt-oss-20b`, `qwen/qwen3.8-27b`: 30 запросов/мин, 1000/день, 8000 токенов/мин и 200 000/день. Длинные запросы генерации могут не помещаться в минутную квоту. |
| Gemini Developer API | Бесплатные входные и выходные токены у `gemini-3.5-flash-lite` | Точные квоты выдаются проекту и показываются в AI Studio. Публичная таблица не позволяет обещать конкретное число запросов. Региональная доступность и верификация аккаунта требуют проверки. |
| OpenRouter `:free` | Нулевая стоимость моделей с суффиксом `:free`, без покупки кредитов | 20 запросов/мин и 50/день без пополнений. Неудачные запросы тоже расходуют дневной лимит. |

Источники таблицы: [Cloudflare pricing](https://developers.cloudflare.com/workers-ai/platform/pricing/), [Groq rate limits](https://console.groq.com/docs/rate-limits), [Groq billing](https://console.groq.com/docs/billing-faqs), [Gemini pricing](https://ai.google.dev/gemini-api/docs/pricing), [Gemini limits](https://ai.google.dev/gemini-api/docs/rate-limits), [OpenRouter free models](https://openrouter.ai/collections/free-models).

## Cloudflare: что подтверждено и что ещё проверить

Квота Workers Free восстанавливается в 00:00 UTC. Платный перерасход требует Workers Paid; для сохранения требования бесплатности аккаунт следует оставить на Free. `gpt-oss-120b` отсутствует в опубликованном перечне моделей с обязательным платным способом оплаты. Для него указаны 31 818 Neurons за миллион входных токенов и 68 182 за миллион выходных. [Тариф и модели](https://developers.cloudflare.com/workers-ai/platform/pricing/).

Наши прежние измерения на Gemma: бережная генерация использовала около 19 тысяч входных и тысячи выходных токенов; обычная с доработками — около 132 тысяч входных и 3,7 тысячи выходных. При переносе этих объёмов в тариф GPT-OSS получается примерно 673 и 4453 Neurons: ориентировочно 14 бережных или две тяжёлые генерации в сутки без остального использования. Это расчёт, а не замер Cloudflare; другая токенизация, reasoning и число исправлений могут изменить результат. [Наш протокол](../acceptance/vps-ollama-acceptance-2026-11-08.json).

Модель поддерживает function calling и имеет параметр `response_format`. Однако общий список JSON Mode не перечисляет GPT-OSS; обещать native JSON Schema без реального вызова нельзя. В списке явно присутствует `@cf/meta/llama-3.3-70b-instruct-fp8-fast`. Документация также предупреждает о возможных отказах JSON Mode и отсутствии потокового вывода в этом режиме. Нужна проверка совместимости либо схема в инструкциях с обязательной проверкой Pydantic. [JSON Mode](https://developers.cloudflare.com/workers-ai/features/json-mode/), [GPT-OSS](https://developers.cloudflare.com/workers-ai/models/gpt-oss-120b/).

## Почему Groq остаётся запасным кандидатом

Groq подтверждает function calling и JSON mode для GPT-OSS. Параллельные вызовы инструментов у GPT-OSS не поддерживаются. Native Structured Outputs доступны, включая strict mode, но сейчас не совмещаются с tool use или streaming. Для нашего автора с MCP потребуется согласовать режим вывода или разделить получение данных и финальную выдачу. [Tool use](https://console.groq.com/docs/tool-use/overview), [Structured Outputs](https://console.groq.com/docs/structured-outputs).

Суточные 200 тысяч токенов и минутные 8 тысяч относятся ко всей организации. По прежним измерениям один сложный запуск способен израсходовать большую часть дневной квоты; наличие окна 131 072 токена не отменяет меньший минутный лимит. Это ограничивает применимость Groq без сокращения контекста и ожидания восстановления квоты. Старые рекомендации бесплатных `llama-3.3-70b-versatile` и `llama-3.1-8b-instant` не следует переносить: текущая страница относит их к Enterprise с Contact Sales. [Лимиты](https://console.groq.com/docs/rate-limits), [Текущие модели](https://console.groq.com/docs/models).

## Gemini и OpenRouter

Gemini официально оставляет Free tier для Flash-Lite; включать billing для перехода на платный tier не требуется. Для некоторых проектов нужна верификация. Россия отсутствует в опубликованном списке доступных регионов; соответствие конкретного аккаунта и расположения серверного запроса нужно установить до выбора. Бесплатные запросы могут использоваться Google для улучшения продуктов. [Pricing](https://ai.google.dev/gemini-api/docs/pricing), [Usage tiers](https://ai.google.dev/gemini-api/docs/rate-limits), [Regions](https://ai.google.dev/gemini-api/docs/available-regions).

У OpenRouter повышение до 1000 бесплатных запросов в день требует покупки кредитов и поэтому не удовлетворяет условию без оплаты. При 50 запросах в день один запуск, подобный нашему примеру с 15 обращениями к модели, оставляет мало места для диагностики и обсуждений. Это резерв для небольшой демонстрации; совместимость конкретной бесплатной модели с tools и output нужно проверять отдельно. [Free models и квоты](https://openrouter.ai/collections/free-models), [Limits](https://openrouter.ai/docs/api-reference/limits).

## Следующий шаг

Нужны Cloudflare Account ID и API token с доступом к Workers AI на аккаунте Workers Free. До изменения VPS выполнить живой пробный прогон: функция → настоящий MCP → структурированный ответ; затем карточка/обсуждение с цитатой и генерация с обеими рецензиями. Зафиксировать расход Neurons, задержки и реальный предел бесплатного аккаунта. Только после этого считать замену рабочей.
