# Ручная приемка Chrome

Этап отложен решением пользователя от 21 октября 2026 года. Эта инструкция применяется только после его явного решения заняться расширением по [SPEC §2.1](../SPEC.md#21-текущая-работа-только-web). Проверки, сборка и установка расширения сейчас не требуются и не блокируют веб-поставку.

Этот список сохраняет незавершенную приемку расширения в настоящем Chrome по требованиям до 21 октября. Текущие границы заданы в [SPEC.md](../SPEC.md); [задача #15](https://github.com/GlebNM/language_tutor/issues/15) теперь охватывает только веб-поставку. Перед будущей приемкой расширения этот список нужно согласовать с явно открытым этапом. Выполнение кода и автоматические тесты сами по себе не отмечают пункты пройденными.

20 октября пользователь выбрал ручную проверку по этому списку и сохранение приватного репозитория. Публичная публикация для A13 больше не требуется. Текущая установка открывается по адресу `http://localhost:18765`; в панели укажите `http://127.0.0.1:18765`. Если порт изменен в `.env`, используйте его.

## Начните с импорта

Соберите актуальное расширение и файлы для проверки из корня репозитория:

```sh
python3 scripts/package-extension.py
python3 scripts/prepare-chrome-acceptance.py
```

ZIP расширения: `dist/language-tutor-extension.zip`. Файлы проверки: `dist/chrome-acceptance/`, архив для скачивания — `dist/chrome-acceptance-files.zip`. Все субтитры взяты из разрешенного подготовленного примера; источники и изменения описаны в `SOURCE.md` внутри набора.

Сначала установите или перезагрузите расширение по инструкции ниже. Откройте [Elephants Dream](https://www.youtube.com/watch?v=TLkA0RELQ1g), импортируйте `full.srt` и проверьте клик по слову, паузу, явное продолжение, карточку и сохранение знакомости. Затем пройдите VTT и неполную дорожку из A2. После этого отдельно выполните A1 на четырех роликах. Такой порядок проверяет учебный сценарий, даже если извлечение снова вернет пустой ответ; сам A1 в таком случае остается непройденным.

## Подготовка и общий профиль

- [ ] Запустите Compose по [README](../README.md) и откройте локальное приложение. Запишите фактический порт из `.env`. Для входа через подписку следуйте настройке OAuth из README.
- [ ] Соберите production ZIP командой `python3 scripts/package-extension.py`, распакуйте его в отдельную папку и загрузите ее через «Загрузить распакованное расширение» в `chrome://extensions`. Можно сразу выбрать каталог `apps/extension`. Для уже установленной копии нажмите «Обновить» на карточке расширения и обновите страницы YouTube.
- [ ] Добавьте точный origin расширения `chrome-extension://<ID>` в `ALLOWED_ORIGINS`, сохранив разрешенные локальные адреса приложения. Пересоздайте сервис `app` и разрешите расширению доступ к выбранному `http://127.0.0.1:<порт>` по инструкции [docs/extension.md](extension.md).
- [ ] Откройте веб-приложение напрямую без расширения и страницу обычного YouTube-видео с расширением. Убедитесь, что оба интерфейса открывают учебный профиль без регистрации и используют один backend.
- [ ] Запишите дату, версию Chrome и ОС, версию/ID расширения, способ установки, порт приложения и ID материала. Для AI-сценариев добавьте модель и reasoning. Не записывайте credentials, коды OAuth, подписанные URL или полные чужие субтитры.
- [ ] Выполните `docker compose ps`: приложение должно быть опубликовано только на loopback, а MCP не должен иметь опубликованного порта хоста. Сравните профиль, материал и исходную оценку слова в вебе и расширении.

Сохраняйте реальные результаты и ссылки на снимки экрана в [таблице приемки](acceptance.md). Если проверка не выполнялась или закончилась ошибкой, оставьте критерий открытым и запишите фактический результат.

## A1 — автоматическое извлечение

Для каждой строки откройте ролик в Chrome, откройте панель, включите учебный режим и нажмите «Повторить автоматическое извлечение», чтобы сохраненная версия не заменила новый запрос. Дождитесь ответа. Не используйте ранее импортированную дорожку как доказательство. Успешная строка должна показывать полный исходный английский ответ, ожидаемый источник, непустую дорожку и корректные реплики в начале, середине и конце ролика.

В исследовании 19 октября 2026 года публичный запрос для этих четырех роликов получил HTTP 200 и 0 байт. Это отрицательный результат прежней проверки, а не результат новой проверки production-расширения в Chrome. Предыдущие Chrome-отчеты для других роликов также не прошли; подробности есть в [журнале извлечения](research/caption-extraction-probe.md).

Запишите для каждой строки фактический источник, язык, признак полноты, число реплик, хеш, первую/среднюю/последнюю временную метку и проверенные реплики. Если дорожка недоступна, сохраните показанную ошибку и отметьте строку как неуспешную. Не снимайте полный текст чужих дорожек.

При пустом ответе раскройте «Подробности проверки» и скопируйте код, источник, язык, HTTP-статус и количество полученных байт. Если обычные субтитры YouTube при этом работают, в DevTools → Network можно включить фильтр `timedtext`, затем выключить и включить штатные CC. Для сравнения достаточно HTTP-статуса, размера ответа и имен query-параметров нативного запроса; значения параметров, полный URL и содержимое дорожки передавать не нужно. Если запроса не видно, так и отметьте.

## A2 — импорт SRT/VTT

- [ ] На Elephants Dream импортируйте `full.srt` из подготовленного набора и откройте материал повторно.
- [ ] Импортируйте `full.vtt` для того же ролика. При самостоятельном преобразовании SRT добавьте заголовок `WEBVTT` и замените запятые в миллисекундах на точки: `00:00:15,000` → `00:00:15.000`.
- [ ] В веб-приложении повторите импорт SRT и VTT для того же материала; проверьте, что открывается нужная версия без дубликатов.
- [ ] Импортируйте `invalid.srt` и `empty.srt`: ожидается понятная ошибка без замены прежней версии.
- [ ] Импортируйте `partial.vtt`, снимите признак полноты и подтвердите предупреждение о неполной дорожке и недоступность полного расчета сложности.

## A3 — синхронизация

- [ ] В обычном и театральном режимах проверьте начало, середину и конец доступной дорожки; текущая реплика должна совпадать со временем видео с задержкой не более 0,5 секунды.
- [ ] Воспроизведите, поставьте на паузу, перемотайте назад и вперед, нажмите на слово. Панель должна показывать выбранное вхождение, а видео — остановиться.
- [ ] Закройте карточку и подтвердите, что видео не запускается само. Продолжите просмотр явной кнопкой и проверьте перемотку к временной метке.
- [ ] Повторите проверки в веб-приложении, если в этом запуске нужен новый отчет: прежняя приемка подготовленного видео описана в [результатах проверки материалов](acceptance-materials.md).

## A9 — состояния ошибок AI

- [ ] Во время запроса карточки быстро выберите другое слово. Поздний ответ первого запроса не должен заменить контекст второго.
- [ ] Получите реальную ошибку AI, проверьте понятное сообщение и повтор запроса. В изолированном локальном прогоне можно остановить только приложение командой `docker compose stop app`, вызвать запрос и вернуть сервис командой `docker compose start app`.
- [ ] Запишите фактически увиденные состояния таймаута и ограничения подписки, если они возникают. Не симулируйте их отчетом или скриншотом и не провоцируйте расход лимита только ради проверки. Пока таймаут и лимит не наблюдались в интерфейсе, оставьте A9 частично пройденным.

## A10 — локальный доступ

- [ ] Убедитесь, что и веб-приложение, и панель открываются без регистрации; панель обращается к настроенному локальному backend.
- [ ] Сохраните результат `docker compose ps` с loopback-публикацией приложения и отсутствием публикации MCP на хост.
- [ ] Сверьте журнал расширения и сетевые запросы: они должны идти только к настроенному локальному origin. Несогласованные ID материала, реплики и вхождения должны быть отклонены; имеющиеся API-результаты описаны в [проверке материалов](acceptance-materials.md).

## A11 — переход между видео

- [ ] Включите учебный режим на первом ролике и откройте карточку или диалог.
- [ ] Перейдите на второй ролик через YouTube без перезагрузки вкладки. Проверьте, что старые субтитры, выбранное слово, материал и контекст диалога сброшены.
- [ ] Быстро выберите слово на втором ролике, пока может завершиться старый запрос. Поздний ответ первого ролика не должен появиться на втором.
- [ ] Повторите переход в двух вкладках и убедитесь, что панель показывает активную вкладку и ее материал.

## A15 — общий профиль

- [ ] Откройте один и тот же материал в веб-приложении и расширении. Выберите слово с уже сохраненной ручной оценкой; запишите ID материала, score и ignored.
- [ ] Измените оценку в одном интерфейсе и обновите данные во втором. Проверьте оценку, связанные словоформы и обновленный показатель сложности.
- [ ] Пересоздайте контейнеры без удаления тома и подтвердите те же ID материала, словаря и результата диагностики. Верните измененную оценку к исходному значению после фиксации результата.

## A6/A8/A17 — диагностика и учебный агент

- [ ] Откройте «Диагностика» в панели и пройдите или продолжите все 14 заданий. Завершение должно показать сводку с предварительными оценками и обновить сложность материала; сохраненная ручная оценка из A15 остается ручной.
- [ ] Откройте «Обсудить с агентом» для выбранного слова и попросите найти его в предыдущих материалах. Полный и частичный импорты из A2 дают две версии для проверки. У ответа должен быть настоящий вызов MCP и существующие цитаты с корректным временем; цитата текущего материала перематывает видео с паузой.
- [ ] Спросите о слове, которого нет в добавленных дорожках. Агент должен сообщить об отсутствии совпадений без вымышленных цитат. Повторно откройте диалог и проверьте сохраненную историю.

## A18 — выбор модели и reasoning

- [ ] Запишите исходные модель/reasoning. В панели получите список моделей и поддерживаемых уровней reasoning, сохраните другую пару и проверьте, что она видна в веб-приложении.
- [ ] Создайте контекстную карточку, завершите диагностику из A6 и задайте вопрос агенту из расширения. Запишите модель/reasoning, указанные у каждого нового ответа.
- [ ] Начните запрос карточки с парой A. Пока он выполняется, сохраните пару B в отдельной вкладке веб-приложения. Первый ответ должен сохранить подпись A; следующий запрос или «Сгенерировать заново» должен использовать B. Если первый запрос успел закончиться до смены, этот шаг еще не проверен.
- [ ] Повторно откройте ранее сохраненный диалог или завершенную диагностику с ответом A после выбора B. Старый ответ должен сохранить исходную подпись A; новый ответ агента должен показывать B. Запишите обе пары рядом с соответствующими ответами.
- [ ] Повторно сгенерируйте карточку и подтвердите применение текущей пары. Поменяйте пару из веб-приложения, проверьте обновление панели и сохранение после пересоздания Compose.
- [ ] Если модель недоступна, запишите обычное состояние ошибки; каждый запрос должен завершиться не позднее 30 секунд.
- [ ] Верните исходные модель/reasoning после фиксации результатов.

## A19 — слова видео

- [ ] На полной дорожке проверьте в панели все базовые формы, уровни «Пока не оценено», 0, 1, 2 и 3, порядок групп, подписи и легенду.
- [ ] Проверьте поиск, каждый фильтр уровня, раскрытие словоформ и вхождений, часть речи и число вхождений.
- [ ] Измените знакомость слова и подтвердите сохранение в общем словаре и пересчет сложности. Перейдите по вхождению: видео должно остановиться на нужной временной метке, а карточка — показать выбранную реплику.
- [ ] Перейдите на другое видео и проверьте список нового материала. Для проверки работы списка без AI используйте отдельный локальный профиль без credentials, чтобы не отключать подписку основного профиля.
