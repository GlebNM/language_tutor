# Проверка английских субтитров YouTube

Минимальное распакованное расширение для исследования #2 (F2/A1). Оно получает английскую дорожку открытого видео, показывает синхронные слова поверх плеера и передаёт выбранное вхождение в боковую панель. Сборка и npm не нужны. Автоматический путь ещё не подтверждён в Chrome; результаты и ограничения записаны в [исследовании](../../docs/research/caption-extraction-probe.md).

## Запуск в Chrome

1. Откройте `chrome://extensions`, включите режим разработчика и нажмите «Загрузить распакованное расширение».
2. Выберите папку `apps/extension-probe` из этого репозитория. Нужен Chrome 116 или новее.
3. Откройте обычную страницу `https://www.youtube.com/watch?v=...`. Если страница уже была открыта, обновите её после установки расширения.
4. Нажмите значок расширения, затем «Проверить дорожку». Дорожка запрашивается только после этого действия. Расширение показывает источник и результат проверки; пустой или неверный ответ не выдаётся за полную дорожку.
5. Запустите видео, нажмите слово в своей реплике и проверьте паузу, текст, время и ID в панели. Проверьте обычный и театральный режимы, перемотку и переход между двумя видео через интерфейс YouTube.
6. Нажмите «Скачать результат JSON», чтобы сохранить контракт и метаданные проверки локально. Этот файл содержит субтитры; не публикуйте его без разрешения правообладателя.
7. Нажмите «Выключить слой»: штатные субтитры снова видны. Видео само не запускается. Выключение, смена видео и новая проверка удаляют старый выбранный контекст.

Если YouTube возвращает ошибку, импортируйте разрешённый SRT/VTT через самостоятельное веб-приложение. Расширение является исследованием; импорт, backend, AI, словарь и оценка сложности сюда не подключены. Сбой извлечения не блокирует разработку импорта. Данные хранятся в памяти текущей вкладки; закрытие/обновление страницы их удаляет.

## Отчёт при ошибке

В версии `0.1.1` панель показывает стабильный код ошибки и известные метаданные запроса: время проверки, ID видео, выбранный источник и язык дорожки, HTTP-статус и число прочитанных байт. Неизвестные значения отмечены явно. Нажмите «Скачать отчёт об ошибке JSON», чтобы сохранить эти сведения. Такой отчёт содержит только код ошибки и перечисленные метаданные; URL запроса, заголовки, токены, cookies, текст исключения и тело ответа в него не входят. Успешный результат по-прежнему экспортируется вместе с субтитрами.

После обновления файлов нажмите кнопку перезагрузки расширения на `chrome://extensions`, проверьте там версию `0.1.1`, затем обновите вкладку YouTube и повторите проверку. Пустой HTTP 200 с нулём прочитанных байт остаётся неуспехом извлечения; отчёт помогает исследовать его причину и не подтверждает прохождение A1.

## Повторяемая диагностика

Команда ниже получает публичные watch-страницы без cookies браузера, выбирает авторскую английскую дорожку перед автоматической и проверяет полный ответ JSON3. Она печатает только метаданные, HTTP-статус и размер. Команда не заменяет проверку расширения в настоящем Chrome.

```sh
python3 scripts/caption-probe.py iG9CE55wbtY Ks-_Mh1QhMc DHjqpvDnNGE x7X9w_GIm1s
```

Для локально сохранённого полного ответа JSON3 можно получить тот же контракт, что использует расширение. Последний аргумент — длительность видео в миллисекундах; требуется Node.js 20 или новее.

```sh
node apps/extension-probe/inspect-json3.mjs VIDEO_ID youtube-authored /path/to/response.json 1203000
```

Подписанные URL дорожек, cookies и player response не сохраняются и не печатаются. Расширение имеет доступ только к `https://www.youtube.com/*`, `scripting` и `sidePanel`. Оно не читает историю браузера, данные подписки или локальный профиль обучения. Слой загружается на страницах YouTube, чтобы обрабатывать переходы без перезагрузки; извлечение включается действием пользователя.

## Источники и права

Код исследования написан для этого проекта; код сторонних расширений или yt-dlp не копировался. Использованы официальные описания Chrome и YouTube и исходный код yt-dlp как справочник формата; ссылки и дата находятся в исследовании. Субтитры четырёх чужих видео в репозиторий не включены. Право распространять их не установлено. Сохранённые метаданные наблюдений не являются разрешением на распространение текста или видео.
